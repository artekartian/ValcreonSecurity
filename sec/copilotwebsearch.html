Ograniczenie Web Search w Microsoft 365 Copilot

Jak centralnie sterować domyślnym trybem pracy Copilot, żeby publiczny Web Search był wyłączony w kontekście danych firmowych – a użytkownik nadal mógł korzystać z Copilot Chat i trybu Web do pytań ogólnych.

Status polityki
Cloud Policy
Zakres
Windows Mac iOS Android Office on the web
TL;DR

Trzy rzeczy, które musisz wiedzieć

Web Search w Copilot można ograniczyć centralnie – zasada Allow web search in Copilot w Cloud Policy (config.office.com).
Rekomendowany wariant: wyłączony w Microsoft 365 Copilot (Work mode), włączony w Copilot Web mode i Copilot Chat – praca na danych firmowych bez mieszania z publicznym Internetem.
Wdrażaj etapami – najpierw grupa testowa, potem rozszerzenie. Dla użytkowników bez licencji Microsoft 365 Copilot globalne wyłączenie może mocno ograniczyć Copilot Chat.

Problem

Centralne sterowanie domyślnym trybem Copilot bez ingerencji w preferencje użytkownika.

Czy można domyślnie wyłączyć Web Search w Copilot?

Najbliżej celu jest opcja Cloud Policy Allow web search in Copilot. Polityka nie blokuje całkowicie Web Search – decyduje, w którym trybie Copilot publiczny Internet jest dozwolony, a w którym nie. Administrator nie ustawia preferencji użytkownika „domyślnie bez Web Search”, tylko określa dostępność funkcji w poszczególnych trybach.

Trzy dostępne tryby polityki

Po włączeniu zasady Allow web search in Copilot administrator ma do wyboru trzy warianty.

Wariant 1

Enabled

Web Search włączony zarówno w Microsoft 365 Copilot, jak i w Microsoft 365 Copilot Chat. Pełny dostęp do publicznego Internetu z poziomu Copilot.

Wariant 2

Disabled

Web Search wyłączony zarówno w Microsoft 365 Copilot, jak i w Microsoft 365 Copilot Chat. Najbardziej restrykcyjny tryb.

Wariant 3 – rekomendowany

Disabled w Work mode, Enabled w Web mode i Chat

Praca na danych firmowych bez Internetu, ale Copilot Web mode i Copilot Chat dalej mogą sięgać do Bing dla pytań ogólnych.

Co oznacza „Disabled in Work mode”

Rozróżnienie kontekstu pracy i kontekstu ogólnego w Copilot.

Microsoft 365 Copilot – kontekst pracy Web Search wyłączony. Copilot pracujący na plikach, poczcie, spotkaniach i Teams nie powinien pobierać informacji z publicznego Internetu przez Bing.
Microsoft 365 Copilot – Web mode Web Search włączony. Użytkownik nadal może używać Copilot do pytań ogólnych, researchu i tematów internetowych – poza kontekstem pracy na danych Microsoft 365.
Microsoft 365 Copilot Chat Web Search pozostaje włączony zgodnie z tą polityką. Microsoft rozróżnia Microsoft 365 Copilot i Microsoft 365 Copilot Chat jako odrębne doświadczenia objęte kontrolą Web Search.
Work IQ – uwaga interpretacyjna Nie zakładaj, że „Work IQ = brak Internetu”. Work IQ to warstwa inteligencji kontekstowej dla danych organizacji, agentów i narzędzi – nie sama blokada Web Search.

Gdzie skonfigurować

Microsoft 365 Apps admin center
config.office.com/officeSettings → polityka Copilot: Allow web search in Copilot.

Tworzenie polityk Cloud Policy
config.office.com/officeSettings/officePolicy/createv2

Platformy
Windows, Mac, iOS, Android, Office on the web.

Kiedy warto zastosować

Scenariusze, w których ograniczenie Web Search ma realny sens biznesowy.

Scenariusze biznesowe
Organizacja przetwarza dane poufne, regulowane lub objęte dodatkowymi wymogami compliance.
Użytkownicy mają korzystać z Copilot Chat wyłącznie w oparciu o dane Microsoft 365 – pliki, wiadomości, spotkania.
Firma chce ograniczyć ryzyko mieszania odpowiedzi opartych na danych wewnętrznych z informacjami z publicznego Internetu.
Wdrożenie Copilot jest prowadzone etapami i Web Search ma być udostępniony dopiero po przeszkoleniu użytkowników.
Polityka bezpieczeństwa wymaga centralnej kontroli nad źródłami, z których korzystają narzędzia AI.

Rekomendowany model wdrożenia

Sześć kroków, które porządkują wdrożenie polityki bez ryzyka „zablokowania” użytkowników.

1

Grupa zabezpieczeń

Utwórz w Entra ID grupę zabezpieczeń dla użytkowników, którym Web Search ma być wyłączony w kontekście pracy.

2

Przypisanie licencji

Dodaj do grupy użytkowników z licencją Microsoft 365 Copilot – polityka pełną wartość dostarcza dla licencjonowanych użytkowników.

3

Konfiguracja Cloud Policy

Skonfiguruj zasadę Allow web search in Copilot w wariancie „Disabled in Work mode, Enabled in Web mode and Chat”.

4

Test na kontach pilotażowych

Zweryfikuj działanie ustawienia – Copilot Chat, Copilot w Word, Excel, Outlook, Teams. Sprawdź, czy odpowiedzi w trybie pracy nie zawierają treści z publicznego Internetu.

5

Rozszerzenie zasięgu

Dołącz kolejne grupy lub całą organizację. Komunikuj zmianę użytkownikom – co dalej działa, a co się zmieniło.

6

Wyjątki i dokumentacja

Udokumentuj użytkowników, którym Web Search jest potrzebny do pracy analitycznej, researchu lub komunikacji z klientami.

Uwaga przed wdrożeniem globalnym

Dwa wątki, które łatwo przeoczyć.

Użytkownicy bez licencji Copilot

Wyłączenie Web Search może istotnie ograniczyć możliwość korzystania z Microsoft 365 Copilot Chat, bo użytkownik nie ma dostępu do pełnego trybu pracy opartego na danych Microsoft 365. Przetestuj na różnych typach licencji.

Zmieniające się nazewnictwo

Interfejs Copilot Chat i nazwy trybów (Work IQ, Work mode, Web mode) mogą się zmieniać. Weryfikuj realne zachowanie Copilot Chat na kontach testowych, nie tylko samą konfigurację zasady.

Efekt dla użytkownika i organizacji

Czego można się spodziewać po prawidłowo wdrożonej polityce.

Copilot pozostaje narzędziem do pracy z danymi firmowymi

Użytkownik nadal korzysta z Copilot Chat w kontekście pracy, ale odpowiedzi nie są wzbogacane wynikami z publicznego Internetu. Copilot działa na dokumentach, wiadomościach, spotkaniach i innych zasobach dostępnych zgodnie z uprawnieniami. Organizacja zachowuje większą kontrolę nad źródłami informacji wykorzystywanymi przez AI.

Potrzebujesz wsparcia we wdrożeniu polityki Cloud Policy?
Pomożemy zaprojektować zasadę, przetestować ją na grupie pilotażowej i wdrożyć dla całej organizacji – razem z dokumentacją i komunikacją do użytkowników.
