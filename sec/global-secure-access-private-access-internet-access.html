Private Access i Internet Access w jednej ofercie Global Secure Access

Od 2 listopada 2026 r. organizacje mogą kupować Microsoft Entra Private Access i Microsoft Entra Internet Access razem jako jedną ofertę Microsoft Entra Global Secure Access. Nie jest to nowy produkt, lecz prostszy sposób zakupu obu możliwości.

Co się zmienia

Microsoft udostępnia wspólną ofertę dla organizacji, które chcą objąć prywatny i internetowy ruch jednolitym, świadomym tożsamości modelem dostępu. Microsoft Entra Private Access i Microsoft Entra Internet Access nadal można kupować także oddzielnie.

Nowa wspólna oferta

Microsoft Entra Global Secure Access

Oferta dostępna od 2 listopada 2026 r. łączy dostęp do aplikacji prywatnych i zasobów internetowych ze wspólnym podejściem opartym na tożsamości.

Szerszy pakiet

Microsoft Entra Suite

Obejmuje Global Secure Access, Microsoft Entra ID Governance, Microsoft Entra ID Protection oraz Microsoft Entra Verified ID.

Pakiet Microsoft 365

Microsoft 365 E7

Zawiera Microsoft Entra Suite i jej funkcje Global Secure Access wraz z Microsoft 365 E5, Microsoft 365 Copilot oraz Microsoft Agent 365.

Jedna warstwa dostępu oparta na tożsamości

1

Jedna podstawa tożsamości

Global Secure Access korzysta z użytkowników, grup, aplikacji i zasad Conditional Access zarządzanych już w Microsoft Entra. Nie wymaga utrzymywania osobnego zestawu zsynchronizowanych polityk.

2

Conditional Access dla różnych miejsc docelowych

Warunki związane z tożsamością, urządzeniem i ryzykiem mogą chronić aplikacje prywatne, internet, usługi SaaS i usługi AI, także gdy aplikacja lub protokół nie loguje się przez Microsoft Entra.

3

Ocena przez całą sesję

Universal Continuous Access Evaluation może niemal w czasie rzeczywistym ponownie ocenić dostęp, gdy urządzenie przestanie być zgodne albo ryzyko użytkownika wzrośnie. Nie trzeba czekać na wygaśnięcie tokenu.

4

Te same kontrole dla użytkowników i agentów AI

Warstwa dostępu stosuje mechanizmy świadome tożsamości zarówno do ruchu ludzi, jak i agentów AI działających w imieniu użytkowników.

Funkcje w publicznej wersji zapoznawczej

Ruch TCP i UDP

Cloud Firewall dla klientów

Rozszerza ochronę poza ruch WWW. Pozwala tworzyć reguły Allow i Block według miejsc docelowych, portów i protokołów oraz przypisywać polityki przez Conditional Access.

Filtrowanie WWW

Akcja domyślna „Continue”

Jeśli ruch nie pasuje do aktywnej reguły, ocena przechodzi do następnego profilu zabezpieczeń według priorytetu. Ułatwia to łączenie wspólnej polityki bazowej z wyjątkami dla aplikacji.

Praca zdalna

Obsługa sieci domowej

Użytkownik może korzystać z lokalnych drukarek, routerów i wyświetlaczy bez rozłączania Private Access. Administrator określa, kiedy ruch do lokalnej podsieci może ominąć usługę.

Monitorowanie

Microsoft Entra Health and Alerts

Pomaga wcześniej wykrywać problemy z łącznością i wdrożeniem oraz skracać czas diagnozowania w ramach środowiska Microsoft Entra.

Elastyczne wdrożenie

Wiele profili przekazywania ruchu

Profile Microsoft Entra Private Access można dopasować do różnych użytkowników, urządzeń i aplikacji, również podczas wdrożeń etapowych.

Szyfrowany ruch

Inspekcja TLS z certyfikatami Microsoft

Microsoft zarządza certyfikatami potrzebnymi do inspekcji TLS, ograniczając potrzebę samodzielnego utrzymywania urzędu certyfikacji lub infrastruktury PKI.

Funkcje ogólnie dostępne

HTTP

Niestandardowe nagłówki

Administratorzy mogą stosować własne nagłówki dla określonych aplikacji i usług w Microsoft Entra Internet Access.

Ochrona danych

Microsoft Entra i Microsoft Purview w warstwie sieciowej

Klasyfikacja i polityki Microsoft Purview mogą być egzekwowane przez Microsoft Entra, aby wykrywać poufne pliki i tekst oraz blokować ich wysyłanie do ryzykownych miejsc, w tym niezatwierdzonych narzędzi AI.

Łączniki sieci prywatnej

Inteligentne równoważenie obciążenia

Session Affinity utrzymuje żądania tego samego użytkownika i urządzenia na tym samym łączniku przez całą sesję, co wspiera ciągłość i ogranicza zbędne ponowne uwierzytelnianie.

Universal CAE

Nowe sygnały urządzenia i ryzyka

Wyłączenie, usunięcie lub utrata zgodności urządzenia oraz wysokie ryzyko użytkownika mogą wywołać ponowne uwierzytelnienie i ponowną ocenę zasad Conditional Access.

W skrócie

Co powinien wiedzieć administrator

• to prostszy model zakupu, a nie nowy produkt
• składniki nadal są dostępne osobno
• polityki opierają się na Microsoft Entra i Conditional Access
• ochrona obejmuje użytkowników i agentów AI
• Microsoft rozwija kontrolę ruchu, danych i kondycji usługi

Znaczenie dla organizacji

  • sprawdź, czy wspólna oferta odpowiada zakresowi ruchu prywatnego i internetowego w organizacji,
  • oceń istniejące zasady Conditional Access pod kątem aplikacji prywatnych, SaaS, internetu i usług AI,
  • przeanalizuj możliwość egzekwowania polityk Microsoft Purview w warstwie sieciowej,
  • uwzględnij Universal CAE oraz sygnały urządzeń i ryzyka w projekcie dostępu,
  • rozróżniaj funkcje ogólnie dostępne od tych w publicznej wersji zapoznawczej.
