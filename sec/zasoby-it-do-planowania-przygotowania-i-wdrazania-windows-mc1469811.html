Zasoby IT do planowania, przygotowania i wdrażania Windows

Microsoft udostępnił bezpłatne materiały, które pomagają wdrażać aktualizacje funkcji dla urządzeń z Windows i aplikacji Microsoft 365 przed premierą Windows 11, wersja 26H2.

Model działania

Materiały prowadzą administratora przez trzy etapy: planowanie, przygotowanie i wdrożenie aktualizacji.

Zalecane działanie

Skorzystaj z bezpłatnej ścieżki szkoleniowej

Wszystkie wskazane zasoby są już dostępne. Warto wykorzystać je przed nadchodzącą coroczną aktualizacją funkcji Windows 11, wersja 26H2.

Ścieżka szkoleniowa obejmuje trzy moduły i wspiera uporządkowane wdrożenie aktualizacji na urządzeniach lokalnych i zdalnych.

Trzy etapy wdrożenia

Proces obejmuje planowanie, przygotowanie środowiska oraz właściwe wdrożenie.

1

Zaplanuj

  • poznaj sposób planowania aktualizacji klientów Windows i Microsoft 365 Apps
  • czas modułu szkoleniowego: 23 minuty
2

Przygotuj

  • przygotuj środowisko i urządzenia do wdrożenia aktualizacji
  • czas modułu szkoleniowego: 44 minuty
3

Wdróż

  • przeprowadź wdrożenie aktualizacji Windows i Microsoft 365 Apps
  • czas modułu szkoleniowego: 48 minut

Wpływ na organizację

Uporządkowany proces ma ułatwić szybsze wdrażanie aktualizacji i obsługę pracy zdalnej.

Sprawniejsze aktualizacje

Szybsze wdrożenia

Trzyetapowy model pomaga zespołom IT przygotować działania przed udostępnieniem aktualizacji funkcji i sprawniej przejść do wdrożenia.

Praca rozproszona

Wsparcie urządzeń zdalnych

Dodatkowa seria podcastów

Cztery nagrania Touchstone rozwijają etapy planowania, przygotowania i wdrożenia.

Planowanie

Część pierwsza i druga

Dwa odcinki dotyczą etapu „Plan”. Nagrania trwają odpowiednio 37 i 32 minuty.

Przygotowanie i wdrożenie

Część trzecia i czwarta

Odcinek „Prepare” oraz odcinek „Deploy” trwają po 45 minut.
