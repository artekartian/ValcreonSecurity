Etykietowanie i otwieranie chronionych plików na Macu

Microsoft udostępni dla macOS dwie aplikacje: File Labeler do nadawania etykiet poufności i ochrony plikom oraz File Viewer do otwierania chronionych formatów, których nie obsługuje aplikacja źródłowa.

Osobna instalacja
O co chodzi

Użytkownicy Maców otrzymają funkcje podobne do Windows: etykietowanie wielu typów plików oraz podgląd plików chronionych przez Microsoft Purview.

Najważniejsza zmiana

Ochrona Purview wychodzi poza aplikacje Office na macOS

File Labeler pozwoli zastosować, zmienić lub usunąć etykietę poufności dla obsługiwanych plików, w tym dokumentów Office, PDF, obrazów i plików tekstowych. Operację będzie można wykonać dla jednego lub wielu plików.

File Viewer umożliwi otwieranie chronionych plików, w tym formatów opartych na .pfile, gdy ich aplikacja źródłowa nie obsługuje ochrony.

Co i dlaczego

Komunikat MC1326509, powiązany z Microsoft 365 Roadmap ID 561327, rozszerza Microsoft Purview Information Protection na komputery Mac.

Kontekst

Dotychczas porównywalne narzędzia File Labeler i File Viewer były dostępne na Windows. Klient dla macOS ma ujednolicić klasyfikację i ochronę plików w środowiskach korzystających z obu platform.

  • etykiety i ochrona pozostają z plikiem po przeniesieniu lub udostępnieniu
  • obowiązują istniejące polityki etykiet Microsoft Purview
  • klient nie będzie preinstalowany i wymaga osobnego pobrania
W skrócie

Co trzeba zapamiętać

• File Labeler służy do etykietowania i ochrony plików
• File Viewer otwiera chronione pliki nieobsługiwane przez aplikację źródłową
• obsługiwane są pojedyncze pliki i wiele plików
• istniejące polityki Purview nadal obowiązują
• klient trzeba pobrać i zainstalować osobno
• zaawansowana ochrona oparta na etykietach nie jest jeszcze obsługiwana

Zakres funkcji

Pierwsze wydanie zapewnia podstawowe funkcje etykietowania i odczytu chronionych plików, ale nie pełną zgodność z Windows.

FunkcjaStatus na macOS
Nadawanie, zmiana i usuwanie etykietObsługiwane dla wspieranych typów plików.
Etykietowanie pojedynczych i wielu plikówObsługiwane z możliwością zastosowania etykiety i ochrony.
Otwieranie chronionych plikówObsługiwane, również dla formatów opartych na .pfile.
Zaawansowana ochrona oparta na etykietachNieobsługiwana w pierwszym wydaniu.
Operacja po wskazaniu całego folderuNiedostępna w pierwszym wydaniu.

Co powinna zrobić firma

Nie jest wymagane natychmiastowe działanie, ale klient trzeba wdrożyć osobno.

1

Przejrzyj polityki etykiet

  • sprawdź, czy istniejące etykiety i ustawienia ochrony odpowiadają potrzebom użytkowników macOS
2

Zaplanuj dystrybucję klienta

  • File Labeler i File Viewer nie będą preinstalowane, dlatego wymagają osobnego pobrania i instalacji
3

Poinformuj użytkowników

  • wyjaśnij zastosowanie obu aplikacji oraz ograniczenia pierwszego wydania
Rekomendacja Valcreon

Przetestuj formaty i ochronę przed wdrożeniem

Warto sprawdzić najczęściej używane typy plików, etykietowanie wielu plików oraz otwieranie materiałów chronionych. Procesy wymagające zaawansowanej ochrony opartej na etykietach lub pracy na całych folderach powinny pozostać poza pierwszym wdrożeniem.
