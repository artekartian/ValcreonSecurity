Project Online Essentials kończy działanie 1 października 2026

Licencja Project Online Essentials osiągnie koniec życia. Przed 1 października 2026 organizacja musi wskazać użytkowników tej licencji i przypisać im obsługiwany zamiennik, jeżeli nadal potrzebują dostępu do Project Online, Project Server lub Planner Premium.

O co chodzi

Po dacie wycofania Project Online Essentials nie zapewni już użytkownikowi dostępu ani praw licencyjnych. Migracja wymaga dobrania licencji do faktycznie używanych funkcji.

Wymagane działanie do 1 października 2026

Brak migracji może przerwać dostęp użytkowników

Project Online Essentials nie jest dostępny w sprzedaży od 1 października 2025, a 1 października 2026 osiągnie koniec życia.

Użytkownicy, którzy nadal potrzebują Planner Premium lub odpowiednich praw dostępu do Project Server, muszą otrzymać obsługiwaną licencję zastępczą przed datą wycofania.

Co i dlaczego

Komunikat MC1466302 wymaga przeglądu użytkowników Project Online Essentials i przeprowadzenia migracji licencji przed datą zakończenia wsparcia.

Kontekst

Project Online Essentials zapewnia obecnie prawa licencyjne do Project Online oraz Project Server przez Client Access Licenses. Po wycofaniu licencji te uprawnienia nie będą dalej zapewniane przez ten produkt.

  • należy ustalić, kto nadal ma przypisaną licencję Essentials
  • trzeba rozdzielić wymagania Planner Premium od wymagań Project Server
  • licencję zastępczą należy przypisać przed datą wycofania
W skrócie

Co trzeba zapamiętać

• Project Online Essentials kończy życie 1 października 2026
• po tej dacie licencja nie zapewni dostępu
• Plan 1 lub Plan 3 może zastąpić Essentials
• sam Project Server może wymagać odpowiednich CAL
• migrację trzeba zakończyć przed terminem

Dobór licencji zastępczej

Właściwy zamiennik zależy od tego, czy użytkownik potrzebuje Planner Premium, Project Server, czy obu elementów.

Potrzeba użytkownikaZalecany kierunek
Planner Premium lub szersze funkcje planowaniaProject and Planner Plan 1 albo Plan 3, zależnie od wymaganego zakresu funkcji.
Planner Premium i prawa do obsługiwanych scenariuszy ProjectProject and Planner Plan 1 lub Plan 3 zapewnia szersze możliwości niż Project Online Essentials.
Tylko Project Server Subscription EditionOdpowiednie Project Server CAL dobrane do wymaganego dostępu.

Kogo dotyczy

Zmiana obejmuje organizacje mające użytkowników z aktywną licencją Project Online Essentials.

Usługa

Project Online

Po wycofaniu użytkownik nie zachowa dostępu na podstawie Project Online Essentials.

Serwer

Project Server

Organizacja powinna zweryfikować wymagane prawa CAL, szczególnie dla Project Server Subscription Edition.

Planowanie

Planner Premium

Użytkownicy wymagający funkcji Premium powinni otrzymać odpowiedni Project and Planner Plan.

Harmonogram

Termin jest ostateczny i wymaga zakończenia zmian licencyjnych przed datą wycofania.

Sprzedaż zakończona

1 października 2025

End of Life

1 października 2026

Licencja kończy życie i przestaje zapewniać użytkownikom dostęp oraz wynikające z niej prawa licencyjne.

Co powinna zrobić firma

Inwentaryzację i migrację należy zakończyć przed 1 października 2026.

1

Zidentyfikuj użytkowników

  • przejrzyj konta z przypisaną licencją Project Online Essentials
2

Ustal wymagany dostęp

  • określ, kto potrzebuje Planner Premium, Project Server lub obu zakresów
3

Dobierz zamiennik

  • przypisz Plan 1, Plan 3 albo odpowiednie Project Server CAL zgodnie z potrzebą
4

Zakończ migrację przed terminem

  • zweryfikuj dostęp po zmianie i poinformuj osoby, których zakres funkcji lub licencja ulegnie zmianie
