Powrót do Security Hub MC1409303
Microsoft Purview Information Protection

Microsoft Edge zacznie blokować zrzuty ekranu chronionych dokumentów PDF

Microsoft rozszerza ochronę dokumentów oznaczonych etykietami Microsoft Purview Information Protection. Dokumenty PDF przechowywane w OneDrive i SharePoint będą blokować wykonywanie zrzutów ekranu podczas przeglądania w Microsoft Edge, jeżeli etykieta zawiera ustawienie „Do Not Allow Screen Capture”.

Co się zmienia

Microsoft usuwa lukę pomiędzy aplikacjami desktopowymi i przeglądarką internetową.

Dotychczas dokumenty PDF oznaczone etykietami Microsoft Purview mogły nie egzekwować ograniczenia „Do Not Allow Screen Capture” podczas wyświetlania w przeglądarce.

Po wdrożeniu aktualizacji Microsoft Edge zacznie blokować wykonywanie zrzutów ekranu dla chronionych dokumentów PDF otwieranych z OneDrive for Business oraz SharePoint Online.

Microsoft ujednolica w ten sposób zachowanie ochrony informacji pomiędzy aplikacjami desktopowymi Microsoft 365 a środowiskiem webowym.

Zmiana będzie włączona automatycznie dla organizacji korzystających z etykiet wrażliwości zawierających ustawienie „Do Not Allow Screen Capture”.

Sierpień 2026

Globalne wdrożenie rozpocznie się w połowie sierpnia 2026 i powinno zakończyć się pod koniec sierpnia 2026.

Kogo dotyczy zmiana

Największy wpływ odczują organizacje korzystające z Microsoft Purview.

Microsoft Purview

Etykiety wrażliwości

Organizacje wykorzystujące Microsoft Purview Information Protection i etykiety służące do ochrony dokumentów.

OneDrive i SharePoint

Dokumenty PDF

Użytkownicy otwierający dokumenty PDF zapisane w OneDrive for Business lub SharePoint Online.

Microsoft Edge

Ochrona będzie wspierana w Microsoft Edge. Inne przeglądarki internetowe nie są objęte pierwszym wdrożeniem.

Co zobaczą użytkownicy

Zmiana będzie działała automatycznie na podstawie etykiet.

Ochrona

Blokada zrzutów ekranu

PDF oznaczony etykietą zawierającą „Do Not Allow Screen Capture” nie pozwoli wykonać standardowego zrzutu ekranu w Microsoft Edge.

Automatycznie

Bez dodatkowej konfiguracji

Microsoft wykorzysta już istniejące etykiety i polityki Purview. Nie trzeba tworzyć nowych etykiet.

Bez zmian

Nieoznaczone dokumenty

Dokumenty bez etykiet ochrony lub bez ograniczenia przechwytywania ekranu nie zostaną objęte zmianą.

Co powinien zrobić administrator

Warto przygotować organizację jeszcze przed wdrożeniem.

Sprawdź etykiety Purview

Zweryfikuj, które etykiety wykorzystują ustawienie „Do Not Allow Screen Capture” oraz czy są stosowane zgodnie z przeznaczeniem.

Poinformuj użytkowników

Przygotuj komunikację dla działów pracujących z dokumentami zawierającymi informacje poufne.

Zaktualizuj procedury helpdesk

Użytkownicy mogą zgłaszać, że nie mogą wykonać zrzutu ekranu. W rzeczywistości będzie to efekt nowego zabezpieczenia.

Zweryfikuj wykorzystanie Edge

Jeżeli organizacja chce spójnego egzekwowania ochrony dokumentów, warto przeanalizować polityki przeglądarek oraz wykorzystanie Microsoft Edge.

Dlaczego to jest ważne

Microsoft Purview Information Protection od lat pozwala kontrolować kopiowanie, drukowanie czy przekazywanie dokumentów.

Zrzuty ekranu pozostawały jednak jednym z najczęściej wykorzystywanych sposobów obejścia zabezpieczeń podczas pracy w przeglądarce.

Nowa funkcja rozszerza istniejące mechanizmy ochrony informacji także na środowisko webowe i zwiększa skuteczność ochrony danych biznesowych.
