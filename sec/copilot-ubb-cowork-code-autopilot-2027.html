Copilot UBB: Cowork, Code i Autopilot widoczne domyślnie

Microsoft zmienia sposób odkrywania środowisk rozliczanych według użycia w aplikacji Copilot. Od końca stycznia 2027 użytkownicy z licencją Microsoft 365 Copilot zobaczą punkty wejścia do Cowork, Code i Autopilot, nawet jeśli organizacja nie udostępniła im jeszcze dostępu.

Co się zmienia?

Punkty wejścia do Cowork, Code i Autopilot będą domyślnie widoczne dla użytkowników z licencją Microsoft 365 Copilot. Osoby bez odpowiednich zasad wydatków zobaczą opcję wysłania prośby o dostęp albo uzyskania dodatkowych informacji, zależnie od konfiguracji organizacji. Microsoft wydłużył harmonogram wdrożenia i doda kontrolę pozwalającą wskazać własny adres URL z instrukcjami.

Harmonogram

Trzy etapy wdrożenia opisane w komunikacie MC1546354.

1

Połowa listopada 2026

W centrum administracyjnym Microsoft 365 pojawi się ustawienie „Access requests to usage-based billing experiences”. Administratorzy będą mogli określić, kto może prosić o dostęp.

2

Połowa grudnia 2026

Ustawienie otrzyma opcję własnego adresu URL. Link do instrukcji organizacji będzie dostępny po wybraniu opcji „Specific users” albo „No users”.

3

Koniec stycznia 2027

Nowy sposób prezentowania funkcji oraz nowe ustawienie zaczną obowiązywać. Dotychczasowe ustawienie „Allow users to discover and use AI experiences enabled by usage-based billing” zostanie wycofane. Dla klientów korzystających z odroczonego wydania zmiana zacznie obowiązywać pod koniec lutego 2027.

Wpływ na organizację

Zmiana dotyczy organizacji z użytkownikami posiadającymi licencję Microsoft 365 Copilot.

Widoczność

Punkty wejścia pojawią się domyślnie

Od końca stycznia 2027 licencjonowani użytkownicy zobaczą Cowork, Code i Autopilot w aplikacji Microsoft Copilot.

Brak zasad wydatków

Prośba o dostęp lub informacje

Użytkownik bez odpowiedniej zasady wydatków zobaczy „Request access” albo „Learn more”, zgodnie z ustawieniem administratora.

Kontrola administratora

Można ograniczyć prośby

Administrator określi, którzy użytkownicy mogą wysyłać prośby o dostęp. Możliwe będzie również całkowite wyłączenie próśb.

Własne instrukcje

Link do wskazówek organizacji

Użytkownicy, którzy nie mogą prosić o dostęp, mogą zobaczyć dodatkowy link „Your organization’s guidance” prowadzący do własnych instrukcji organizacji.

Ważne

Sama widoczność nie uruchamia rozliczeń

Zmiana nie włącza automatycznie środowisk rozliczanych według użycia i nie inicjuje naliczania opłat. Do korzystania z funkcji potrzebna jest odpowiednia zasada wydatków oraz dostępne Copilot Credits.

Zakres

Aplikacja Copilot i centrum administracyjne

Zmiany obejmują aplikację Microsoft Copilot oraz centrum administracyjne Microsoft 365. Obecne ustawienie dotyczące odkrywania funkcji UBB pozostanie aktywne do końca stycznia 2027.

Zalecane działania

Konfigurację warto zakończyć przed wymuszeniem nowego sposobu odkrywania funkcji.

1. Nowe ustawienie

Sprawdź konfigurację w listopadzie

Po udostępnieniu ustawienia przejrzyj je w centrum administracyjnym Microsoft 365.

Ścieżka: Copilot > Settings > Access requests to usage-based billing experiences.
2. Prośby o dostęp

Wskaż uprawnionych użytkowników

Ustal, kto może prosić o dostęp do Cowork, Code i Autopilot, a kto powinien otrzymać wyłącznie informacje.

3. Instrukcje organizacji

Przygotuj własny adres URL

Od połowy grudnia będzie można wskazać stronę z wewnętrznymi zasadami lub instrukcjami dla użytkowników, którzy nie mogą wysłać prośby o dostęp.

4. Kontrola kosztów

Przejrzyj zasady wydatków

Sprawdź, czy zasady wydatków i dostępność Copilot Credits odpowiadają wymaganiom organizacji.

Zgodność i dokumentacja

Aktualizacja dodaje kontrolę próśb o dostęp i możliwość kierowania użytkowników do instrukcji organizacji. Nie przyznaje automatycznie dostępu i nie zmienia wymagań istniejących zasad wydatków.
