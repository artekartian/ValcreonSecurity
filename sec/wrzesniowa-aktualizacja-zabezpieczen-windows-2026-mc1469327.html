Wrześniowa aktualizacja zabezpieczeń Windows 2026

Aktualizacja jest dostępna dla wszystkich wspieranych wersji Windows. Microsoft zaleca jej szybkie zainstalowanie.

O co chodzi

Pakiet zawiera poprawki bezpieczeństwa, ulepszenia stosu obsługi oraz zmiany związane z kontrolowanym wdrażaniem nowych certyfikatów Secure Boot.

Wymagane działanie

Zaplanuj szybkie wdrożenie aktualizacji

Wrześniowa aktualizacja zabezpieczeń została opublikowana dla wspieranych wersji klienckich i serwerowych systemu Windows. Organizacje powinny wdrożyć poprawki zgodnie ze swoim procesem zarządzania aktualizacjami.

Na ograniczonej liczbie urządzeń instalacja może wymagać jednego dodatkowego restartu po zastosowaniu aktualizacji certyfikatów Secure Boot.

Windows 11 25H2

Najważniejsze elementy wskazane przez Microsoft dla aktualizacji KB5124008.

Co zawiera aktualizacja

  • ulepszenia wprowadzone wcześniej w KB5120998 z 27 sierpnia 2026
  • większy zakres danych do kwalifikowania urządzeń do nowych certyfikatów Secure Boot
  • ulepszenia stosu obsługi, czyli komponentu instalującego aktualizacje Windows
W skrócie

Co trzeba zapamiętać

• aktualizacja bezpieczeństwa jest już dostępna
• zalecana jest szybka instalacja
• nowe certyfikaty Secure Boot są wdrażane etapami
• urządzenie może uruchomić się ponownie dodatkowy raz

Secure Boot i dodatkowy restart

Aktualizacja certyfikatów jest wdrażana w sposób kontrolowany i etapowy.

Kwalifikowanie urządzeń

Certyfikat trafia na gotowe urządzenia

Microsoft rozszerza dane używane do wyboru urządzeń, które mogą automatycznie otrzymać nowe certyfikaty Secure Boot. Certyfikaty są przekazywane dopiero po wykryciu wystarczającej liczby pozytywnych sygnałów aktualizacji.

Wpływ na użytkownika

Możliwy jeden dodatkowy restart

Ograniczona liczba urządzeń konsumenckich i firmowych może uruchomić się ponownie jeden dodatkowy raz. Jest to jednorazowy restart po zastosowaniu aktualizacji certyfikatów Secure Boot.

Co powinien zrobić administrator

Krótka lista działań przed szerokim wdrożeniem.

1

Sprawdź wersje systemów

  • zidentyfikuj używane wersje Windows 10, Windows 11 i Windows Server oraz odpowiadające im numery KB
2

Przetestuj aktualizację

  • wdroż poprawki na grupie testowej zgodnie z obowiązującym procesem aktualizacji
3

Zaplanuj wdrożenie

  • po pozytywnej weryfikacji udostępnij aktualizacje pozostałym wspieranym urządzeniom
4

Poinformuj użytkowników

  • uwzględnij możliwość jednego dodatkowego restartu związanego z certyfikatami Secure Boot
Rekomendacja 1sec.pl

Monitoruj wdrożenie i restarty

Aktualizację należy najpierw sprawdzić na reprezentatywnej grupie urządzeń, a następnie wdrożyć szerzej. W komunikacji dla użytkowników warto wskazać możliwość dodatkowego restartu.
