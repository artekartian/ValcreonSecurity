Microsoft naprawia problemy po wrześniowej aktualizacji Windows

Microsoft opublikował awaryjną aktualizację Out-of-Band (OOB), która usuwa problemy występujące na części urządzeń po instalacji aktualizacji zabezpieczeń Windows z 8 września 2026 r.

Wymagane działanie

Wdróż aktualizację OOB na urządzeniach objętych problemem

Aktualizacja została wydana 14 września 2026 r. Dla większości wersji Windows jest pakietem skumulowanym i zawiera poprawki z aktualizacji zabezpieczeń opublikowanej 8 września 2026 r.

Wyjątkiem są urządzenia korzystające z hotpatch. Muszą mieć zainstalowaną wrześniową aktualizację zabezpieczeń, aby automatycznie otrzymać odpowiadającą jej aktualizację hotpatch.

Naprawione problemy

Poprawki dotyczą wirtualizacji, usług pulpitu zdalnego oraz wybranych urządzeń audio USB.

Co mogło przestać działać

  • udostępnione foldery hosta w maszynach wirtualnych Linux opartych na Hyper-V
  • Remote Desktop Services, w tym tworzenie nowych sesji oraz logowanie lokalne i zdalne
  • urządzenia USB Audio Class 1.0 pracujące w trybach dźwięku wielokanałowego
W skrócie

Co trzeba zapamiętać

• poprawka OOB jest już dostępna
• dla nowszych wersji Windows 11 jest aktualizacją zabezpieczeń
• pakiety są dostępne w Windows Update, WSUS i Microsoft Update Catalog
• Windows 11 23H2 i Windows 10 22H2 ESU otrzymują aktualizację opcjonalną
• hotpatch wymaga wcześniejszej aktualizacji z 8 września

Sposób dystrybucji

Windows 11 26H1, 25H2 i 24H2

Automatyczna instalacja

Aktualizacja OOB jest aktualizacją zabezpieczeń. Pobiera się i instaluje automatycznie przez Windows Update oraz Windows Update for Business zgodnie ze skonfigurowanymi zasadami. Jest również dostępna w Microsoft Update Catalog i synchronizuje się z WSUS.

Windows 11 23H2 i Windows 10 22H2 ESU

Aktualizacja opcjonalna

Aby ją zainstalować, przejdź do ustawień Windows Update, wyszukaj aktualizacje, a następnie wybierz pobranie i instalację. Pakiet jest także dostępny w Microsoft Update Catalog.

Hotpatch i poprawki bezpieczeństwa

Hotpatch

Windows 11 25H2 i 24H2

Odpowiadająca aktualizacja hotpatch jest dostępna dla urządzeń zapisanych do aktualizacji hotpatch. Urządzenie musi wcześniej mieć zainstalowaną aktualizację zabezpieczeń z września 2026 r.

Bezpieczeństwo

Dodatkowe poprawki CVE

Pakiety dla Windows 11 26H1, 25H2 i 24H2 zawierają poprawkę dla CVE-2026-62721. Pakiet dla Windows 11 26H1 zawiera także poprawkę dla CVE-2026-85921.

Co powinien zrobić administrator

  • sprawdź, które urządzenia otrzymały aktualizację zabezpieczeń z 8 września 2026 r.
  • nadaj priorytet urządzeniom korzystającym z Hyper-V, Remote Desktop Services lub wielokanałowych urządzeń USB Audio Class 1.0
  • zweryfikuj synchronizację odpowiednich pakietów w WSUS
  • dla Windows 11 23H2 i Windows 10 22H2 ESU zaplanuj instalację opcjonalnej aktualizacji
  • w środowiskach hotpatch potwierdź obecność wrześniowej aktualizacji bazowej
