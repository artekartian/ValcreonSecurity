Microsoft Graph przejmuje obsługę archiwów Exchange Online

Microsoft rozszerza obsługę archiwów skrzynek pocztowych w Microsoft Graph. To element przygotowań do wycofania Exchange Web Services (EWS) w Exchange Online.

Najważniejsze
MC1469565
Graph API
EWS
Archive Mailboxes
Termin

EWS będzie wyłączany od października 2026 i ma zostać całkowicie wyłączony do kwietnia 2027.

Co się zmienia

Microsoft Graph będzie obsługiwał scenariusze związane z archiwami skrzynek pocztowych, które wcześniej często wykorzystywały EWS.

Import i eksport

Dane skrzynek

Graph udostępnia interfejsy do importu i eksportu danych skrzynek pocztowych.

Archiwa

Zarządzanie folderami

Dostępne są API do zarządzania folderami w archiwach skrzynek pocztowych.

Compliance

Purview i eDiscovery

Zmiana dotyczy rozwiązań compliance, backupu, eksportu danych i eDiscovery.

Kogo dotyczy

Organizacji używających aplikacji lub narzędzi korzystających z EWS dla archiwów Exchange Online.

Przykłady

Najczęstsze rozwiązania

• eDiscovery
• backup i eksport danych
• procesy compliance
• Data Lifecycle Management
• własne aplikacje korzystające z archiwów

Ryzyko

Po wyłączeniu EWS

Aplikacje i skrypty korzystające z EWS do obsługi archiwów mogą przestać działać, jeśli nie zostaną zaktualizowane do Microsoft Graph.

Co należy zrobić

Microsoft wymaga przygotowania migracji przed październikiem 2026.

1

Zidentyfikuj EWS

Sprawdź aplikacje, skrypty i narzędzia korzystające z EWS dla archiwów Exchange.

2

Zweryfikuj dostawców

Potwierdź plany migracji u producentów rozwiązań zewnętrznych.

3

Przejdź na Graph

Zaktualizuj aplikacje do obsługi Microsoft Graph API.

4

Przetestuj archiwa

Zweryfikuj działanie archiwów, szczególnie w środowiskach z auto-expanding archives.

W skrócie

Najważniejsze informacje

• EWS jest wycofywany w Exchange Online
• Microsoft Graph zyskuje obsługę archiwów
• dotyczy Purview, eDiscovery i backupów
• wymagane może być dostosowanie aplikacji
• migrację warto rozpocząć przed październikiem 2026

Dla administratorów

Jeżeli organizacja korzysta z archiwów Exchange Online przez EWS, należy zweryfikować rozwiązania compliance, backupowe i integracje własne przed wyłączeniem tej technologii.
